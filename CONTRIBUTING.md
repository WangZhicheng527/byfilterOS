贡献指南

中文版本：

首先，感谢你愿意花时间为 byFilterOS 贡献力量！

提交 Bug 报告或功能建议：
请通过 GitHub Issues 提交。
描述问题时，请尽量提供清晰的复现步骤、环境信息（编译器版本、硬件平台等）。
如果是功能建议，请说明该功能解决了什么问题，以及它如何与 byFilterOS 的设计理念契合。

提交代码 (Pull Request)：
    1. 复刻 (Fork) 本仓库到你的 GitHub 账号。
    2. 在你的复刻版本中，创建一个新的分支进行修改（不要直接在 main 分支上修改）。
    3. 完成修改后，请确保代码风格与项目保持一致，提交信息清晰简洁。
    4. 向本仓库的 main 分支提交 Pull Request (PR)。
    5. 重要：所有的 PR 都需要经过维护者的审核 (Review)。审核通过后，PR 才会被合并。

提交信息建议：
建议采用 "类型: 简短描述" 的格式，例如 feat: 添加任务调度器。
类型可以是：feat（新功能）、fix（修复）、docs（文档）、style（格式）、refactor（重构）、test（测试）等。

Contributing Guide

First of all, thank you for taking the time to contribute to byFilterOS!

Bug Reports & Feature Requests:
Please submit through GitHub Issues.
For bug reports, provide clear reproduction steps and environment details (compiler version, hardware platform, etc.).
For feature requests, explain what problem it solves and how it aligns with byFilterOS's design philosophy.

Submitting Code (Pull Request):
    1. Fork this repository to your GitHub account.
    2. In your fork, create a new branch for your changes (do not modify the main branch directly).
    3. Before submitting, please ensure code style is consistent and commit messages are clear.
    4. Submit a Pull Request (PR) to the main branch of this repository.
    5. Important: All PRs require review by the maintainer. PRs will only be merged after approval.

Commit Message Guidelines:
We recommend the format "type: short description", e.g., feat: add task scheduler.
Types include: feat (new feature), fix (bug fix), docs (documentation), style (formatting), refactor (refactoring), test (testing), etc.
